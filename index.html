Qué comprueba

Cada archivo se contrasta con mmp.xsd, el esquema que define el formato: polígonos, puntos, capas de imagen, grupos y estilos.

Estructura XML

XML bien formado, etiquetas cerradas y elemento raíz correcto.

Elementos del formato

Elementos desconocidos y campos obligatorios que faltan o están vacíos.

Tipos y rangos

Latitudes y longitudes, números, valores 0/1, colores hexadecimales y valores permitidos.

Ubicación de cada error

La ruta del elemento, el valor encontrado y la línea del archivo donde aparece.

Recursos

  • Esquema XSD mmp.xsd La definición completa del formato, con tipos y rangos.
  • DTD mmp.dtd Versión simplificada: no comprueba tipos ni rangos.
  • Archivo de ejemplo Full.mmp Un proyecto completo y válido para tomar como referencia.
  • Código fuente en GitHub El validador, el esquema y los archivos de prueba.

Para que tu editor valide un archivo mientras lo escribes, enlaza el esquema en el elemento raíz:

xsi:noNamespaceSchemaLocation="https://raw.githubusercontent.com/blueblinkone/mmp-validator/refs/heads/main/mmp.xsd"
